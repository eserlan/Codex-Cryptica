# Vault Audit

The **Vault Audit** is a checklist for your vault. It counts the entries that are missing something, so you can see what still needs work and go straight to those entries.

## Open it

- In the **Table**, choose **Audit** in the toolbar. Choose **Audit** again to return to the full table list.
- Or use the **Vault Audit** card on the Front Page.

## What it checks

The **Findings** tab shows one card for each gap, with a count:

| Card                  | What it counts                                  |
| --------------------- | ----------------------------------------------- |
| **Missing portraits** | Entries with no image, or only a placeholder    |
| **No summary**        | Entries with an empty description               |
| **No connections**    | Entries that are not connected to anything else |
| **Unlabelled**        | Entries with no labels                          |
| **All flagged**       | Entries missing any of the above                |

Choose a card to filter the table to just those entries. From there you can open an entry and fill in the gap.

## Quick presets

Presets filter the table for common jobs, such as **Characters missing portraits**, **Unconnected characters** and **Sparse locations**. A preset replaces your current search and filters. To go back, use **Clear all filters** in the table.

## Distribution

Switch to the **Distribution** tab to see how your entries are spread across types and labels. Choose a type or label to filter the table to it.

## Good to know

- The audit only reads your vault. It never changes an entry.
- It runs on your device, so nothing is sent anywhere.
