# Categories and Labels

Open **Settings** and choose the **Schema** tab to define how your world is organised. It has two parts: **categories**, which give entries their type, colour and icon, and **Campaign Labels**, a list of the labels used across your vault.

## Categories

A category is the kind of thing an entry is, such as Character or Location. Categories colour the nodes on the graph and group entries in the Explorer and the Entity Table, so a set of your own ones can match how you think about your world.

Each category in the list has:

- a **colour**, chosen with the colour picker;
- a **name**, which you edit in place. If you clear the box, the old name comes back;
- an **icon**, chosen with **Change icon** from the Glyph Library of 36 icons;
- a **Delete category** button.

### Adding a category

1. At the bottom of the list, pick a colour, type a name under **New category...** and choose an icon.
2. Choose **ADD**.

A category with the same name as an existing one is refused with "Category already exists".

### Deleting a category

Choose **Delete category** and confirm. Your entries are not deleted: entries that used the category fall back to the default style.

### Reset to defaults

**RESET TO DEFAULTS** puts the category list back to the built-in set straight away. **It asks for no confirmation.** Any categories you added are removed from the list, and any colours, names or icons you changed on the built-in ones are put back. Entries that used a removed category fall back to the default style.

## Campaign Labels

**Project Labels** lists every label in use in your vault. You can tidy them here, and the change applies to all of your entries at once:

- **Rename** a label to change it on every entry that has it. Labels are stored in lower case, so "Character" becomes "character". If a label with that name already exists, you are asked whether to merge the two, and an entry that had both ends up with just one. When it is done you are told how many entries changed.
- **Delete** a label to remove it from every entry that has it. Before anything happens you are told how many entries will lose the label, and the entries themselves are never deleted.

To add a label to particular entries instead, use the **Add label** box on an entry, or **Add / remove labels** and **Manage Labels** in the [Entity Table](/help#help/entity-table). To find entries by label, search with `#label` in the [Explorer](/help#help/entity-explorer) or the Entity Table.
