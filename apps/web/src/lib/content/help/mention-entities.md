## Mention an entity in a question

Type **@** in the Lore Oracle input, then start typing a name. A short list of matching entities appears above the input. Choose one and the Oracle answers from that exact entry.

- **Pick with the mouse or a tap**: select the entity in the list.
- **Pick with the keyboard**: use **Up** and **Down** to move, then **Enter** or **Tab** to choose.
- **Close the list**: press **Escape**. Your text stays as it is.

A chosen entity appears in the message as a link. Select the link to open the entity.

### Mention several entities

Add as many mentions as you need in one question, for example "How is @Elara Voss connected to @Royal Academy of Pagen?". Every mentioned entity is included in what the Oracle reads.

### Type a name without picking

You can type `@` and a name, then send. If one entity matches the name or one of its aliases, the Oracle uses it. If several entities match, the Oracle asks you which one you mean. Choose one, or choose **Send as text** to send the message without a link. If nothing matches, you see a short note and the message is sent as plain text.

### What the Oracle can see

- Only entities in the Vault you have open are offered.
- In a guest or shared view, hidden entities are never suggested, linked, or sent to the Oracle. A mention for one is sent as plain text.
- In your own Vault, mentions follow the same rules as the rest of the Oracle's context.
- Mentions only pin an entity into the Oracle's context. Your entries are not changed.

### Limits

- Mentions work in the Lore Oracle for the Vault you have open.
- They are not available in the Cif help assistant or in VTT Chat yet.
- When an entity is renamed, its mention shows the new name. When an entity is deleted, the mention shows as unavailable and is no longer a link.

See [The Lore Oracle](/help#help/oracle-guide) for the wider chat workflow.
