# Session Prep Builder

Open the [Session Prep Builder](/tools/session-prep-builder) to prepare a situation for play. You can answer the questions and copy a run sheet without an account or AI.

## Answer the questions

Start with a hook, last session's fallout or the current campaign situation. Work through **Start**, **Pressure**, **People**, **Places**, **Information**, **Complications**, **Consequences** and **Reserve**. The builder prepares people, pressures and options rather than a fixed scene order or ending.

Write your own answers, or explicitly ask AI to answer an empty question. Suggestions appear as options you can keep, edit or reject. **Redraft** replaces a section only when you request it, and you can undo that redraft. AI additions are marked.

When using AI, your hook, prep, instructions and rejected ideas are sent to Google's Gemini API for suggestions. Codex analytics do not collect their text. Without AI, you can answer the questions and build the run sheet online or offline.

## Build and keep the run sheet

Choose **Build my run sheet** to arrange your answers into a run sheet. If you edit the prep afterwards, use **Update run sheet** to include those changes. The builder also flags necessary facts that have only one way to be found.

You can copy the result. Saving opens Codex Cryptica so you can choose a local campaign vault; it does not automatically publish your prep. Cif can explain these steps, but cannot generate answers, save a run sheet or change your prep for you.

Session Prep is different from **Session Journal**, which records what happened during play, and **Session Hub**, which holds generated drafts for reuse.
