# Help Assistant

The help assistant answers questions about using Codex Cryptica. It knows which screen you are on, so "how do I connect this?" gets an answer for what you are looking at.

## Asking a question

Open the help button at the bottom right, or choose **Ask about this** on an entity's Connections tab. Type your question and press **Ask**. Every answer lists the help articles it came from, so you can read more.

## Being shown where something is

Sometimes the assistant offers to show you a control. Choose **Show me** and it opens the right tab and outlines the button with a label. It only points at things. It never changes your vault, and you can clear the outline any time by pressing Escape.

## What is sent

Your question, the last few questions in this conversation, and a short description of the screen you are on, such as "an entity's Connections tab". No entity names, text, or IDs are sent. Avoid typing private lore into the question, because the question itself goes to our AI service.

## When it cannot answer

If the help does not cover your question, the assistant says so and suggests the closest topics instead of guessing. If you are offline, or the assistant is not reachable, you will see the help articles for your screen instead.

## Turning it off

Turn on **AI Disabled** in Settings and the help assistant disappears. The help library is still there.
