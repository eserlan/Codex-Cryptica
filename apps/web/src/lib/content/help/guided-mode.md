# Guided Mode

Use the **Guided / Full Toolbox** switch to choose how many tools the workspace shows. Guided mode starts enabled for new users. Your choice is remembered in this browser across worlds.

## Finding tools

**Guided** keeps the tool selection smaller and offers creation choices suited to what you are working on. **Full Toolbox** shows the full tool selection. Switching modes does not delete, rewrite or hide your campaign entities.

Contextual suggestions can help you extend your world. You choose whether to follow or dismiss them; Cif can explain the workflow but cannot create entities or accept suggestions for you.

## Quick Start World

Quick Start World is a separate creation action. Choose a world genre and look, review the preview of four to six linked entities, and optionally enter a seed premise. **Generate Starter World** creates a new vault with those entries and connections.

When AI is available, the Oracle writes the entries. Otherwise the built-in generator takes over. This action creates content immediately; it is different from switching Guided mode or asking Cif a question.

In a shared or read-only vault, use the views available to you. Changing the tool selection does not grant permission to edit that vault.
