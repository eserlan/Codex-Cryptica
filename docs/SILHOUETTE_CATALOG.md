# Codex Cryptica Silhouette Library Catalog

This document catalogs all **100 vector silhouettes** available in Codex Cryptica.
All silhouettes are hosted on Cloudflare R2 under the `codex-cryptica-statics` bucket and served globally via `https://assets.codexcryptica.com/`.

All silhouettes use `fill="currentColor"` so they automatically adopt the primary theme accent color across the Cytoscape graph view, the entity inspector avatar, and preview selectors.

For the creation and vectorization process, refer to [`docs/SILHOUETTE_PIPELINE.md`](./SILHOUETTE_PIPELINE.md).

For the public interactive web gallery with live theme preview and SVG exports, visit [`/silhouettes`](https://codexcryptica.com/silhouettes).
