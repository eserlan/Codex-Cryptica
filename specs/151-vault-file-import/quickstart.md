# Quickstart: Import Files from Another Vault

1. In the vault that should receive the files, open **Import from Another Vault**.
2. Choose the source vault from the list of other vaults in this browser.
3. Browse its files and select the ones you want (individually, several, or all).
4. Review the summary: how many files (and images) will be added, how many paths conflict and will be skipped, and any referenced images that couldn't be found.
5. Choose **Import** to copy the selected files, their referenced images, and thumbnails into the current vault.
6. The current vault stays active; imported files are searchable/visible immediately, and the completion message reports what was added, skipped, or missing.
