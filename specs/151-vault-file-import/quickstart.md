# Quickstart: Import Files from the File System

1. In the vault that should receive the files, open **Import Files**.
2. Drag the files (or a folder) you want from your file system onto the drop area, or use **Choose Files** to open the traditional file upload dialog.
3. Review what was picked up. If a file references an image that wasn't included, you'll be prompted to add it directly or (where supported) let the app look in the source folder.
4. Review the summary: how many files (and images) will be added, how many paths conflict and will be skipped, and any images still missing.
5. Choose **Import** to copy the selected files, resolved images, and thumbnails into the current vault.
6. The current vault stays active; imported files are searchable/visible immediately, and the completion message reports what was added, skipped, or missing.
