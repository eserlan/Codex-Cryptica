# Quickstart: Current Vault File Import

1. Open **Settings → Vault → Portable Backup** in the vault that should receive the files.
2. Under **Add to Current Vault**, drag in a `.codex.zip` backup or choose it from your device.
3. Check the source vault name and the counts of files to add and conflicts to skip.
4. Choose **Add Files** to copy only new paths into the current vault.
5. Review the completion message; any matching paths were left untouched.
