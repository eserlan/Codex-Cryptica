## 1. Schema Extensions & Key Interfaces

### `StarterConstellationConfig`

Configuration passed to `packages/generator-engine` to build a starter constellation.

```typescript
export interface StarterConstellationConfig {
  themeId: string; // One of CC's 15 supported theme IDs (e.g. 'fantasy', 'cyberpunk', 'space-opera')
  premise?: string; // Optional user seed sentence / premise
  useAI?: boolean; // Whether to call Gemini AI or use local fallback (default: true)
}
```

### `StarterConstellationResult`

Output generated by `packages/generator-engine` containing entities and the relationship edges that link them into one connected web.

```typescript
export interface StarterConstellationResult {
  themeId: string;
  title: string; // Overall world / scenario title
  summary: string; // Concise scenario summary
  entities: ConstellationEntity[];
  relationships: ConstellationRelationship[];
}

export interface ConstellationEntity {
  id: string;
  title: string;
  type: "location" | "character" | "faction" | "event" | "item" | "threat";
  subtype: string; // Theme-specific subtype (e.g., 'district', 'corporation', 'gang')
  summary: string;
  content: string; // Full markdown content
  labels: string[];
}

export interface ConstellationRelationship {
  sourceId: string;
  targetId: string;
  relation: string; // e.g. 'located in', 'leads', 'conflicts with', 'threatens'
  /**
   * Accepted from local/AI generation but NOT acted on when saving: the web
   * app always creates exactly one connection, sourceId → targetId, in the
   * direction implied by `relation` (e.g. Settlement → located in → Region).
   * A single connection already renders as one graph edge; creating the
   * reverse direction too produces a duplicate, backwards-reading edge.
   */
  bidirectional?: boolean;
}
```

## 2. Intent Creation Data Contract

### `IntentCreateOptions`

Input for context-aware entity creation (`+ Create`).

```typescript
export type IntentCategory =
  "character" | "place" | "faction" | "event" | "item" | "custom";

export interface IntentCreateOptions {
  category: IntentCategory;
  themeId: string;
  parentEntityId?: string;
  parentEntityTitle?: string;
  parentEntityType?: string;
  customPrompt?: string;
}
```

## 3. Structural Recommendation Data Contract

### `ContextualRecommendation`

Structure returned by the heuristic recommendation evaluator.

```typescript
export interface ContextualRecommendation {
  id: string;
  parentEntityId: string;
  promptText: string; // e.g. "Who leads the Iron Syndicate?"
  targetCategory: IntentCategory;
  relationType: string; // e.g. "leader", "settlement", "base_location"
  actionLabel: string; // e.g. "Add Leader"
}
```
